YAHYA Clothing Website - HTML, CSS and JavaScript

FILES:
- index.html
- style.css
- script.js

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).

WHATSAPP SETUP:
Open script.js and find:
const whatsappNumber = "923XXXXXXXXX";
Replace it with your WhatsApp number including country code, without +, spaces or dashes.
Example format: 923001234567

When customer clicks Checkout on WhatsApp, WhatsApp opens with their cart/order details pre-filled. The customer must press Send to submit the order.

No login or signup page is included. Product names and prices are demo data; edit the products array in script.js.
